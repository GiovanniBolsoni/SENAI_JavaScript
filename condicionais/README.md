# Estruturas Condicionais 🔀

Estudo sobre como tomar decisões no código com base em condições, usando `if`, `else`, `else if` e `switch/case`.

## Arquivos

- **`condicionais.js`** — Arquivo de estudo com anotações e exemplos comentados sobre:
  - `if`, `else`, `else if` e `switch/case`;
  - Exemplos práticos: verificação de temperatura, nível de bateria e sistema de acesso por tipo de usuário (`admin`/`cliente`), incluindo o uso de `toLowerCase()`/`toUpperCase()` para padronizar textos digitados.
- **`index.html`** — Página de apoio para testar os exemplos do `condicionais.js` no console.

- **`exercicios_fixacao/exercicios_condicionais.js`** — Exercícios de fixação, incluindo:
  - Verificação de maioridade;
  - Verificação se um número é positivo ou negativo;
  - Aprovação em uma prova com base na nota;
  - E outros cenários de decisão simples usando `if/else`.
- **`exercicios_fixacao/index.html`** — Página de apoio para os exercícios de fixação.

- **`lanchonete_brasaburguer/`** — Mini-projeto **"Brasa Burguer"**: simula um pedido de lanchonete via `prompt()`, em que o cliente informa o nome e o produto (X-Salada, X-Bacon ou X-Tudo). O preço é definido com uma cadeia de `if/else if` de acordo com o produto escolhido, e o total da compra é calculado multiplicando o preço unitário pela quantidade pedida.

## O que foi praticado

- Construir cadeias de decisão (`if / else if / else`) para tratar múltiplos cenários;
- Validar e padronizar entradas de texto do usuário;
- Aplicar condicionais em um cenário prático de cálculo de pedido (lanchonete).
