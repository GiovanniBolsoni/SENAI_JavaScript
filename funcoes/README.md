# Funções 🧩

Estudo sobre funções em JavaScript, com foco em funções nativas de array que ajudam a manter o código mais limpo e organizado, evitando repetição.

## Arquivos

- **`funcoes.js`** — Arquivo de estudo com anotações e exemplos comentados sobre funções nativas de array, como:
  - `map` — percorre uma lista e cria uma nova lista transformada;
  - `filter` — filtra os itens de uma lista com base em uma condição;
  - `find` — encontra o primeiro item que atende a uma condição;
  - Uso de funções tradicionais e arrow functions.
- **`index.html`** — Página de apoio para testar os exemplos do `funcoes.js` no console.

- **`exercicios_fixacao/exercicios_funcoes.js`** — Exercícios de fixação, incluindo:
  - Exibir uma lista numerada de nomes usando `forEach` com índice;
  - Exibir a posição de cada item de um array (cores);
  - Acessar o primeiro e o último item de um array;
  - E outros exercícios de reforço com métodos de array.
- **`exercicios_fixacao/index.html`** — Página de apoio para rodar os exercícios de fixação.

- **`atividade_ListadeProdutos/`** — Mini-projeto **"Lista de Produtos"**: a partir de um array de produtos (nome e preço), o script aplica:
  - `filter` para encontrar os produtos com preço acima de R$ 500;
  - `find` para localizar um produto específico pelo nome ("Mouse");
  - `map` para gerar um novo array contendo apenas os nomes dos produtos.

## O que foi praticado

- Criar e utilizar funções para organizar e reaproveitar lógica;
- Aplicar `map`, `filter` e `find` para transformar, filtrar e buscar dados em arrays de objetos, um padrão muito comum em aplicações reais.
