# Variáveis 📦

Estudo introdutório sobre declaração de variáveis, tipos primitivos, conversão de tipos e operadores em JavaScript.

## Arquivos

- **`variaveis.js`** — Arquivo de estudo com anotações e exemplos comentados sobre:
  - Diferença entre `let`, `const` e `var`;
  - `console.log`, concatenação e interpolação de strings (template literals);
  - Tipos primitivos: `string`, `number`, `boolean`, `undefined`, `null`;
  - Conversão de tipos implícita e explícita (`Number()`, `String()`);
  - Operadores relacionais (`>`, `<`, `==`, `===` etc.) e matemáticos (`+`, `-`, `*`, `/`, `%`, `**`);
  - Operadores lógicos (`&&`, `||`, `!`);
  - Arrays e objetos básicos;
  - Entrada de dados do usuário com `prompt()` e `alert()`.

  > Os exemplos estão comentados propositalmente: o arquivo foi usado durante a aula para testar trecho por trecho no console do navegador.

- **`index.html`** — Página usada para carregar o `variaveis.js` e testar os exemplos no console (F12).

- **`exercicios_fixacao/exercicios_variaveis.js`** — Exercícios de fixação aplicando os conceitos de variáveis, tipos e operadores vistos na teoria.
- **`exercicios_fixacao/index.html`** — Página de apoio para rodar os exercícios de fixação.

## O que foi praticado

- Declarar e reatribuir variáveis corretamente conforme a mutabilidade necessária;
- Diferenciar tipos de dados e realizar conversões entre eles;
- Aplicar operadores relacionais, matemáticos e lógicos em pequenos exemplos práticos.
