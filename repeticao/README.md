# Estruturas de Repetição 🔁

Estudo sobre laços de repetição (loops), usados para executar um bloco de código várias vezes com base em uma condição.

## Arquivos

- **`repeticao.js`** — Arquivo de estudo com anotações e exemplos comentados sobre os quatro tipos de repetição:
  - `for` — usado quando já se sabe quantas vezes o bloco deve se repetir;
  - `while` — repete enquanto uma condição for verdadeira;
  - `do while` — repete o bloco pelo menos uma vez antes de checar a condição;
  - `forEach` — percorre os itens de um array.
- **`index.html`** — Página de apoio para testar os exemplos do `repeticao.js` no console.

- **`exercicios_fixacao/exercicios_repeticao.js`** — Exercícios de fixação, incluindo:
  - Contagem de 1 a 10 com `for`;
  - Exibição da tabuada de um número digitado pelo usuário;
  - Soma dos primeiros N números naturais usando `while`;
  - E outros exercícios de reforço com laços de repetição.
- **`exercicios_fixacao/index.html`** — Página de apoio para rodar os exercícios de fixação.

## O que foi praticado

- Escolher o tipo de laço mais adequado para cada situação (`for` vs `while` vs `do while`);
- Percorrer arrays com `forEach`;
- Resolver problemas práticos de contagem, soma e tabuada usando repetição.
